# MVP 与路线图

## MVP 必需功能

- 普通用户注册、登录、退出。
- 登录页记住账号，避免重复输入邮箱或账号名。
- 主密码初始化。
- 创建默认个人保险库。
- 密码条目 CRUD。
- 每条密码记录支持主要密码、副密码列表和副密码备注。
- 密码条目搜索、收藏、归档。
- 导入/导出入口。
- 密码生成器。
- 敏感字段加密保存。
- 客户端与服务端敏感通讯使用非对称加密机制保护。
- PWA 基础能力：Manifest、Service Worker、可安装体验、离线页、静态资源缓存。
- 移动端优先 UI：手机端登录、保险库列表、条目详情、新建/编辑、生成器、设置和日志页面。
- 审计日志。
- 基础安全设置：修改主密码、恢复码、活跃会话。

## MVP 排除范围

- 团队、组织、成员邀请、共享权限。
- 团队管理员、系统管理员、后台管理。
- 浏览器插件。
- 原生移动 App。
- 企业 SSO。
- 高级报表。
- 自动填充。
- 离线完整保险库；MVP 只提供离线应用壳和密码生成器。
- 完整第三方密码管理器批量导入导出；MVP 只保留入口。
- 标签创建、标签编辑、标签筛选、标签批量管理。

## Phase 1：个人基础可用版

- 完成认证和会话。
- 完成个人保险库。
- 完成移动端优先核心页面。
- 完成支持主要密码与副密码列表的密码条目增删改查。
- 完成密码生成器。
- 完成 PWA 基础安装和离线壳。
- 完成基础审计日志。

## Phase 2：个人安全增强版

- 完成主密码修改。
- 完成恢复码。
- 增加活跃会话管理。
- 增加安全事件提醒。
- 可选增加 MFA。

## Phase 3：个人效率增强版

- CSV 导入导出。
- 标签创建、标签编辑、标签筛选。
- 密码健康评分。
- 重复密码检测。
- 泄露密码检测。
- 浏览器插件。

## 后续迭代方向

- 原生移动端应用。
- WebAuthn 无密码登录。
- 更完整的端到端加密密钥迁移。
- 多保险库分组。
- 标签批量管理。

## 风险与依赖

- 加密方案设计错误会造成高安全风险。
- 主密码遗失恢复机制需要谨慎设计。
- 若引入第三方邮件或 MFA 服务，需要外部服务稳定性保障。

## 优先级顺序

1. 安全的数据存储和认证。
2. 非对称加密通讯机制。
3. PWA 基础能力。
4. 移动端优先核心 UI。
5. 密码条目核心 CRUD。
6. 搜索、复制、显示隐藏。
7. 审计日志。
8. 安全设置。
9. 个人效率增强功能。
