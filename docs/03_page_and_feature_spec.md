# 页面与功能规格

## 页面清单

页面规格默认以移动端为主设计；桌面端在同一信息架构上扩展为更宽的列表/详情布局。

| 页面 | 用途 | 优先级 |
|---|---|---|
| 登录页 | 普通用户登录 | MVP |
| 注册页 | 创建账号和主密码 | MVP |
| 个人保险库页 | 展示用户自己的密码条目 | MVP |
| 密码条目详情页 | 查看、复制、编辑、删除条目 | MVP |
| 新建/编辑条目页或弹层 | 创建或修改密码条目 | MVP |
| 密码生成器页或弹层 | 生成随机密码 | MVP |
| 安全设置页 | 修改主密码、恢复码、会话管理 | MVP |
| 审计日志页 | 查看本人关键操作记录 | MVP |
| 数据导入/导出入口 | 从保险库或设置进入数据迁移与备份 | MVP 入口，完整功能后续迭代 |
| PWA 离线页 | 网络不可用时展示离线状态和可执行操作 | MVP |

## 登录页

- 字段：邮箱、登录密码、记住账号复选框。
- 操作：登录、切换记住账号、跳转注册、跳转找回密码。
- 规则：邮箱必填且格式合法；密码必填；连续失败需限流；勾选记住账号后仅保存邮箱或账号名。
- 状态：加载中、登录失败、账号锁定、网络错误。
- 安全限制：不得保存登录密码、主密码、会话令牌、恢复码或任何保险库密钥；取消勾选后应清除本地保存的账号标识。

## 个人保险库页

- 字段展示：标题、网址、用户名、更新时间、收藏状态。
- 操作：新建、搜索、排序、导入入口、导出入口、收藏、归档。
- 移动端布局：顶部搜索栏 + 条目卡片列表 + 底部导航 + 右下角新建按钮。
- 导入/导出入口：移动端可放在搜索下方的工具行，或放入更多菜单；入口文案使用“导入”“导出”。
- 桌面端布局：可扩展为侧边导航 + 列表 + 详情预览。
- 搜索规则：支持标题、网址、用户名模糊搜索。
- 筛选规则：按收藏、归档状态筛选。
- 排序规则：最近更新、标题 A-Z、创建时间。
- 空状态：提示创建第一个密码条目。

## 密码条目详情页

- 字段：标题、网址、用户名、主要密码、副密码列表、TOTP 密钥、备注、自定义字段。
- 副密码列表字段：副密码值、副密码备注、排序。
- 操作：复制用户名、复制主要密码、复制副密码、显示主要密码、显示副密码、编辑、归档、删除。
- URL 字段：只提供新窗口打开所记录 URL 的图标入口，不提供显示或复制按钮。
- Username 字段：只提供复制图标入口，不提供显示按钮。
- 操作按钮规则：详情页内字段级操作全部使用图标按钮展示，不使用 `Show`、`Copy`、`Edit` 等文字按钮；图标按钮必须有可访问名称。
- 移动端布局：单页详情，主要密码和每条副密码都必须有独立图标复制入口；副密码复制图标靠近对应副密码备注和值，危险操作收纳到底部或更多菜单。
- 规则：主要密码和副密码默认隐藏；显示任意密码需要二次验证或短期解锁。
- 错误状态：解密失败、无权访问、条目不存在。

## 新建/编辑条目页

- 必填字段：标题。
- 可选字段：网址、用户名、主要密码、副密码列表、备注、TOTP 密钥。
- 副密码编辑规则：允许添加、删除、修改、排序多个副密码；每个副密码包含密码值和备注；副密码备注建议必填，便于区分用途。
- 移动端布局：全屏表单，底部固定保存按钮，密码生成器从底部抽屉打开。
- 表单规则：网址必须是合法 URL 或允许为空；密码长度建议不少于 12 位。
- 保存规则：主要密码、副密码值、副密码备注、TOTP、备注等敏感字段保存前加密。

## 密码生成器

- 可配置项：长度、大小写字母、数字、符号、排除易混字符。
- 默认值：长度 20，包含大小写字母、数字、符号。
- 操作：生成、复制、填入当前表单。

## 功能模块

- 认证模块：注册、登录、退出、会话。
- 个人保险库模块：默认保险库、保险库信息。
- 密码条目模块：CRUD、搜索、收藏、归档。
- 密码生成器模块：随机密码生成和复制。
- 审计日志模块：记录登录、查看主要密码、查看副密码、复制主要密码、复制副密码、创建、更新、删除。
- 设置模块：主密码、恢复码、活跃会话。
- 数据管理模块：导入入口、导出入口、导入/导出安全提示。
- PWA 模块：Manifest、Service Worker、安装提示、离线壳、静态资源缓存、网络状态提示。

## 数据导入/导出入口

- 入口位置：个人保险库页工具行、设置页的数据管理分区。
- 导入入口：进入导入说明页或导入弹层，MVP 可先支持 CSV 方向或显示后续支持说明。
- 导出入口：进入导出确认流程，必须提示导出文件包含敏感信息，应妥善保存。
- 安全规则：导入和导出涉及敏感数据，必须走非对称加密通讯；导出操作应记录审计日志。

## Tags 后期开发项

- MVP 不提供标签创建、标签编辑、标签筛选或标签批量管理。
- 当前 UI 设计稿中如出现标签样式，仅作为未来功能的视觉占位，不作为 MVP 验收项。
- 后期可增加标签选择器、标签管理页、按标签筛选、标签批量管理和标签搜索。

## PWA 离线页

- 展示条件：用户离线或 API 不可达。
- 内容：网络不可用提示、重试按钮、返回首页按钮。
- 规则：MVP 不在离线页展示密码明文，不缓存完整保险库数据。
- 可用能力：已缓存的应用壳、基础导航、密码生成器可离线使用。
