# Figma 生成提示

## 产品定位

为 PasswdMan2 生成一个专业、安全、面向普通用户的个人密码管理 PWA 站点界面。UI 以移动端为主进行设计，手机端是主体验，桌面端只是响应式扩展。界面应像高频个人工具台，而不是营销落地页。核心体验是快速查找、查看、复制、创建和管理个人加密密码条目；每条记录包含主要密码以及若干副密码和副密码备注。

## 页面列表

- 登录页
- 注册页
- 个人保险库页
- 密码条目详情页
- 新建/编辑密码条目弹层
- 密码生成器弹层
- 安全设置页
- 审计日志页
- PWA 离线页
- PWA 安装提示

## 设计风格

- 视觉：简洁、克制、可信赖。
- 色彩：中性色背景，安全状态使用绿色或蓝色，危险操作使用红色，警告使用琥珀色。
- 字体：清晰易读，信息密度适合工具型站点。
- 圆角：卡片和输入控件使用 6-8px 圆角。
- 避免：大面积装饰渐变、营销式大 Hero、过度插画、团队管理入口、管理员后台入口。
- PWA 表达：可以设计安装提示、离线状态和独立窗口下的导航状态，但不要把它做成移动 App 营销页。
- 设计优先级：先完成移动端 390px 宽度设计，再提供桌面端扩展布局。

## 组件库要求

- 使用 MUI 作为实现组件库，设计稿中的组件应能映射到 MUI。
- MUI Button：primary、secondary、ghost、danger、icon-only。
- MUI TextField：默认、聚焦、错误、禁用、密码输入、搜索输入。
- MUI IconButton：显示/隐藏、复制、外链打开、编辑、更多、删除。
- MUI Checkbox：记住账号。
- MUI Badge/Chip：状态徽标；tags chip 仅作为后期占位。
- MUI Menu/Select：筛选和排序。
- MUI Dialog：删除确认、导出敏感提示。
- MUI Snackbar/Alert：Toast 和错误提示。
- MUI List/ListItem/Card：条目列表与安全设置卡片。
- MUI BottomNavigation：移动端底部导航。
- MUI Drawer：密码生成器、筛选排序、移动端临时面板。
- EmptyState。
- SkeletonLoading。

## 移动端主布局

### 登录页

- 单列登录表单，适配手机竖屏。
- 字段：邮箱、密码、记住账号复选框。
- 操作：登录、切换记住账号、注册入口、忘记密码入口。
- 状态：错误提示、加载中按钮。
- 记住账号说明：只记住邮箱或账号名，不保存密码或主密码。

### 个人保险库页

- 底部导航：保险库、生成器、日志、设置。
- 顶部区域：搜索框、导入入口、导出入口、筛选按钮、排序按钮。
- 主列表：条目卡片，展示标题、网址、用户名、更新时间、收藏图标；tags 仅作为后期功能占位，不要求创建或筛选交互。
- 主要操作：右下角悬浮新建按钮或底部固定新建按钮。

### 密码条目详情页

- 标题区：条目名称、收藏、编辑、更多菜单。
- 字段区：网址、用户名、主要密码、副密码列表、TOTP、备注。
- 副密码列表：每项显示副密码备注、隐藏的副密码值、显示按钮、独立复制按钮；复制按钮必须靠近对应副密码，避免误复制。
- 敏感字段：主要密码和副密码默认隐藏，提供显示和复制图标按钮。
- URL 字段只保留新窗口打开外链图标入口；Username 字段只保留复制图标入口。
- 详情页字段级操作全部用图标展示，不使用 `Show`、`Copy`、`Edit` 等文字按钮。
- 危险操作：归档、删除放在底部或更多菜单内。
- 布局：单列详情页，复制按钮靠近对应字段，关键操作适合拇指触达。

### 新建/编辑弹层

- 手机端使用全屏表单。
- 字段：标题、网址、用户名、主要密码、副密码列表、备注。
- 副密码编辑区：支持添加副密码、填写副密码备注、删除副密码、调整顺序。
- 密码字段旁提供生成器入口。
- 底部固定操作：取消、保存。

### 密码生成器弹层

- 显示生成结果。
- 控件：长度滑块、大小写字母、数字、符号、排除易混字符。
- 操作：刷新生成、复制、填入表单。
- 手机端使用底部抽屉或独立页面。

### 安全设置页

- 分区：主密码、活跃会话、恢复码、数据管理、MFA 预留入口。
- 数据管理分区：导入数据、导出数据入口；导出入口需要敏感数据提示。
- 每个分区使用清晰的表单和状态标记。

### 审计日志页

- 表格列：时间、操作、目标、IP、设备。
- 支持搜索、操作类型筛选、时间筛选。

### PWA 离线页

- 显示网络不可用状态。
- 提供重试按钮和返回保险库入口。
- 明确不展示密码明文。
- 可保留密码生成器入口。

### PWA 安装提示

- 使用轻量 Banner 或菜单项。
- 不打断登录、创建条目、复制密码等核心流程。

## 桌面端扩展布局

- 在移动端信息架构基础上扩展。
- 可使用侧边导航替代底部导航。
- 个人保险库页可使用列表 + 详情双栏。
- 新建/编辑可使用右侧抽屉或居中对话框。
- 不要改变移动端已定义的核心流程和字段优先级。

## 交互状态

- 默认、悬停、聚焦、禁用、错误、加载。
- 空列表状态：引导创建第一个密码条目。
- 解密失败状态：显示错误提示和重新登录入口。
- 无权限状态：显示返回按钮。

## 可访问性要求

- 图标按钮必须有文字标签或可访问名称。
- 对比度满足 WCAG AA。
- 表单错误靠近对应字段。
- 键盘焦点状态明显。
